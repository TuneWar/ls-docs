# Input

Alle Input Keys/Mousebuttons innerhalb `Input.<taste>`.

## Maus

- `Input.MOUSE_BUTTON_LEFT`: Linke Maustaste
- `Input.MOUSE_BUTTON_MIDDLE`: Mittlere/Scrollklick
- `Input.MOUSE_BUTTON_NONE`: Keine Maustaste (beim Bewegen der Maus)
- `Input.MOUSE_BUTTON_RIGHT`: Rechte Maustaste
- `Input.MOUSE_BUTTON_WHEEL_DOWN`: Runterscrollen
- `Input.MOUSE_BUTTON_WHEEL_UP`: Hochscrollen
- `Input.MOUSE_BUTTON_X1`
- `Input.MOUSE_BUTTON_X2`
